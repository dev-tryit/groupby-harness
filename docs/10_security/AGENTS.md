# 10_security

보안을 설계하는 단계. 보안은 안전을 위한 것이다.

- 앞 단계(`00`~`09`)를 하나하나 보면서 보안의 허점을 체크하고 막는다. 단계마다 무엇을 보았고, 어떤 허점이 있고, 무엇으로 막는지를 적는다. 허점이 없는 단계도 보았다는 것과 없다고 본 이유를 적는다. 앞 단계가 다 나와야 훑어볼 대상이 생기므로 이 단계는 그 뒤에 온다.
- 막으려면 앞 단계를 고쳐야 하는 허점은 여기서 앞 단계를 고치지 않는다. "막지 못한 것"에 적고 사용자에게 알린다.
- 보안 목표(무엇을 누구로부터 지켜야 하는지)는 `03_prd`를 따른다.
- 여기서 정한 보안 시나리오는 `12_test-scenario`의 완성 조건에 들어간다.
