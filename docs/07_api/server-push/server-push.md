# 서버 푸시

서버가 화면에 한쪽 방향으로 계속 보내는 통신을 적은 문서. 근거는 `04_wireframe/wireframe.html`이다.

## 1. 결론

없다.

## 2. 이유

- 화면이 열릴 때는 결과가 이미 만들어져 있다(`background/background.md`). 진행 상황을 화면에 흘려보낼 일이 없다.
- 화면이 보는 데이터는 열려 있는 동안 바뀌지 않는다.

## 3. 생기는 경우

- 화면에서 공고를 넣고 비교가 끝나기를 기다리게 되면, 지원자마다 비교가 끝난 것을 알리는 데 쓴다. 속도의 목표는 아직 없다(`03_prd/prd.md` 5장).
