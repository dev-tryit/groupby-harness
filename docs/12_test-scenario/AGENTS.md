# 12_test-scenario

테스트 시나리오를 적는 단계. 테스트 시나리오는 코드의 완성 조건이다.

- 시나리오는 "무엇이 되어야 끝난 것인가"를 적는다. 한 부분이 아니라 처음부터 끝까지의 흐름을 다룬다.
- `03_prd`의 핵심 알고리즘에서 정한 성능 기준과 `10_security`의 보안 시나리오도 여기에 들어간다.

## 골든셋 (`golden-set/`)

골든셋은 입력과 기대 결과가 짝지어진 데이터다. 시나리오가 정답지로 쓴다.

- 골든셋은 `golden-set/`에 둔다. 설계 문서가 아니라 설계 문서(`test-scenario.md`)가 가리키는 데이터다.
- 골든셋은 검증하려는 가설을 증명하는 데이터여야 한다. 데이터마다 어떤 가설을 검증하는지가 명확해야 한다.
- 골든셋은 코드를 짜기 전에 확정한다.
- 코드의 결과에 맞춰 골든셋을 고치지 않는다. 골든셋을 고쳐야 하면 `14_report`에 리포트를 쓰고 루프를 돈다.
- 코드가 실행되어 나온 결과물(예: 실행 중에 내려받은 파일)은 골든셋이 아니다. 저장소 폴더가 아니라 인프라의 저장소에 실제로 존재하는 데이터다. 어떤 데이터인지는 `06_data-model`에서, 어디에 저장하는지는 `08_infra`에서 정한다.
