# 02_research

`01_problem`에서 정의한 문제를 대상으로 조사하는 단계.

- 조사는 주제마다 하위 폴더로 나눈다. 하위 폴더 하나에 문서 하나를 쓰고, 문서 이름은 폴더 이름과 같다. 예를 들어 `law/law.md`다.
- 확인한 사실과 해석(추측)을 구분해서 쓴다. 확인하지 못한 것은 확인하지 못했다고 적는다.
- 사실에는 출처와 확인한 날짜를 남긴다.
- 조사는 에이전트 팀으로 한다. 에이전트 하나가 하위 폴더 하나를 맡고, 자기 폴더의 문서만 쓴다. `DECISIONS.md`, `AGENTS.md`, README, `CHECKLIST.md`는 팀을 이끄는 에이전트가 쓴다.
- 조사 문서는 방법을 확정하지 않는다. 선택지와 장단점, 추천 후보와 그 이유까지만 쓴다.
- 하위 폴더는 `01_problem/problem.md`의 문제를 기준으로 나눈다.
- 지금 하는 프로젝트의 조사 주제와 하위 폴더 목록은 `CHECKLIST.md`에 있다.
