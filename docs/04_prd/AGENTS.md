# 04_prd

요구사항분석서를 쓰는 단계.

## 인증과 권한

- 사용자의 역할과 역할마다 할 수 있는 일을 이 단계에서 정한다. 인증과 권한은 모든 API와 화면에 걸치므로 요구사항에서 먼저 정해야 한다.
- 여기서 정한 역할과 권한을 `07_api`의 엔드포인트와 `10_screen-design`의 화면이 따른다.

## 보안과 성능의 목표

- 보안 목표를 이 단계에서 정한다. 무엇을 누구로부터 지켜야 하는지를 적는다. 설계는 `11_security`에서 한다.
- 성능 목표를 이 단계에서 정한다. 얼마나 빨라야 하는지와 사용자와 요청이 얼마나 많은지를 적는다. 데이터의 양은 여기서 정하지 않고 `06_data-model`에서 정한다. 설계는 `08_algorithm`에서 한다.
