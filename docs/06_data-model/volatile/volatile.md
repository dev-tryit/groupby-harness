# 휘발성 데이터

잠깐 쓰고 사라져도 되는 데이터를 적은 문서. 근거는 `03_prd/prd.md`의 2장, 5장이다.

## 1. 결론

없다.

## 2. 이유

| 흔히 두는 것 | 두지 않는 이유 |
| :- | :- |
| 세션 | 인증이 없다(`03_prd/prd.md` 2장) |
| 캐시 | LLM의 결과는 사라지면 안 되는 데이터라 영속 데이터로 둔다. 다시 만들면 비용이 들고 결과가 달라진다(`03_prd/prd.md` 7장). 점수는 계산이 가볍다(조건의 수 × 지원자의 수) |
| 카운터, 요청 제한 | 평가자 한 명이 자기 컴퓨터에서 쓴다(`03_prd/prd.md` 5장) |

## 3. 생기는 경우

- 사용자가 늘어 같은 랭킹을 여러 번 계산하게 되면 계산한 랭킹을 잠깐 담아 둘 자리가 필요해진다.
