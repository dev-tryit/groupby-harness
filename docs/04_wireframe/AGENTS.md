# 04_wireframe

와이어프레임의 목적은 큰 그림을 보는 것이다.

- 서비스 전체의 화면 구성과 흐름을 한눈에 파악할 수 있게 그린다.
- 프론트 코드를 만들기 위한 세부 그림은 여기에 그리지 않는다. 그것은 `09_screen-design`에서 한다.
- 와이어프레임은 로우파이(low-fi)로 그린다. 상자와 글자만으로 무엇이 어디에 있는지를 보인다. 색, 글꼴, 실제 문구는 넣지 않는다.
- 와이어프레임은 마크다운이 아니라 HTML로 만든다. 문서의 이름은 `wireframe.html`이다. 파일 하나로 열리게 하고 바깥의 자원을 불러오지 않는다.
- 실제로 인터랙션하고 페이지를 이동할 수 있게 만든다. 누르면 화면이 바뀌어야 한다.
- 기능의 관점으로 기술한다. 무엇을 누르면 무엇이 일어나는지를 화면 옆에 적는다. 이것이 가장 중요하다.
